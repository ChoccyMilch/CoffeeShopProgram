# Project Overview
Welcome to your core project for CSC-154! In this course, you will experience the complete Software Development Life Cycle (SDLC). You will act as an independent software engineer hired to digitize our campus coffee shop.

## The Scenario: 
The campus coffee shop is tired of writing orders on paper cups. They want a simple digital system where students can place an order, baristas can see the queue and mark drinks as "done," and the manager can update the menu.

## The Goal: 
Because this class focuses on the process of building software, you are not expected to build a fully polished, graphical mobile app. Your goal is to document how this system should work, map out the logic, manage your files using GitHub, and build a basic prototype using the programming skills (Java, Python, or C++) you learned in your introductory coding classes.

------------------------------------
# Focus:
- Simple easy to use program.
# Features:
- Item Menu
- Ability for the manager to add and remove items from the menu.
- Order system that allows a user to select an item and order it. After ordering will tell the user which place their order is in within the queue.
- Queue system that will send a recently ordered item to a queue for the Baristas to see and keep track of. Most recent order will be sent to the back of the queue.
- Ability for baristas to mark orders as completed.
- Invoice list showing all the orders that have been made and completed as well as the total gross revenue of the orders.

# Features that are out of scope:
- Customer menu item customization.
- Online payment systems.
- Fancy graphical UI.
- Customer accounts.
